INTENTFLOW — INVESTOR WEBSITE
==============================

Run locally:
1. Unzip this folder.
2. Double-click index.html.
   OR run a local server:
   - VS Code -> Live Server
   - Python: python -m http.server 5500
     then open http://localhost:5500

Deploy to GitHub Pages:
1. Create a GitHub repository.
2. Upload index.html and README.txt.
3. Settings -> Pages -> Deploy from branch -> main -> /root.
4. Save.

Deploy to Vercel/Netlify:
Upload the folder or connect the GitHub repository. No build command is required.

IMPORTANT:
- Replace "IntentFlow" with your final startup name if needed.
- Replace founders@yourcompany.com in index.html with your real email.
- This is a frontend/investor-facing website. Real authentication, payments,
  commerce APIs and AI-agent execution are not connected in this static demo.
